IATA 货物标签详解

每张标签必备

航空公司名称、空运单号、目的地和主条码。这四项为 IATA 第 606 号决议所要求。

可选信息

始发地、转运点、件号、该件重量、总件数、总重量、操作信息、分运单详情及其他信息。请填写您的航空公司或操作代理要求的内容。

条码

Code 128，16 位：3 位航空公司前缀、8 位空运单序列号、一个分隔用的零和 4 位件号。例如空运单 176-12345675，第 3 件编码为 1761234567500003。

每件一张标签

每件货物都有自己的标签和件号。请贴在靠近收货人地址的一面，并去除或遮盖旧标签。

常见问题

这遵循哪种标签格式？+

IATA 第 606 号决议中的条码货物标签：航空公司名称、空运单号、目的地和 Code 128 主条码为必填项，另有始发地、中转点、件数、重量和分运单信息等可选项。

它能读取我的空运单文件吗？+

可以。选择或拖入空运单的 PDF、JPG 或 PNG 文件，工具会自动填入航空公司、AWB 号、起运地、目的地、总件数和重量。转运点和操作信息等可选项留空，您可按需自行添加。来自航空公司和 e-AWB 系统的 PDF 识别效果最佳。扫描件和照片只要清晰、端正也可以。绿色字段已通过我们的检查，琥珀色字段需要您确认。文件在您自己的设备上读取，不会被上传。

我应该使用什么打印机和标签尺寸？+

4×6 英寸（或 10×15 cm）直接热敏标签打印机的条码效果最佳。您也可以在 A4 纸上打印，每页四张标签，用透明胶带粘贴。务必以 100% 的尺寸打印，不要使用“适应页面”缩放。

每件货物都需要一张标签吗？+

是的。每件货物都有各自的标签，件号是条形码的一部分，因此同一票货物中的每张标签都不相同。如果分批贴标，您可以打印一个范围，例如第 11 件至第 20 件。

校验位警告是什么意思？+

8 位空运单序列号的最后一位，通常是前七位数字除以 7 所得的余数。如果不一致，号码可能输入有误。请对照您的空运单核对。

这些标签可以用于危险品吗？+

可以将它们用作空运单标签，但危险品和锂电池还需要各自的危险标签和标记。您可以在我们的危险品标签页面免费下载。
